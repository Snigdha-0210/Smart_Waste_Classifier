## Reporting a Vulnerability

Security of dependencies and model pipelines is important to us. If you discover a security vulnerability or exploit in the codebase, web interface, or dependencies:

1. **Do not create a public issue.**
2. Report the vulnerability privately to the project repository maintainers via GitHub Security Advisories or by contacting `snigdha@users.noreply.github.com`.
3. Please include:
   - Type of issue (e.g., dependency vulnerability, remote code execution, injection risk)
   - Steps to reproduce
   - Potential impact
4. We will acknowledge receipt of your vulnerability report within 48 hours and provide updates regarding mitigation.
